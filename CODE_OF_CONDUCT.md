# Code of Conduct

Agent Router is an [Agentic AI Foundation](https://aaif.io) project, a Series of
LF Projects, LLC. All participants in the Agent Router community — contributors,
maintainers, and attendees of project meetings and events — must abide by the
[LF Projects Code of Conduct](https://lfprojects.org/policies/code-of-conduct/).

To report an incident, or to appeal the handling of a report, email the Manager of
LF Projects at [manager@lfprojects.org](mailto:manager@lfprojects.org). Reports are
handled confidentially.

Contributions must also follow the
[Linux Foundation Generative AI policy](https://www.linuxfoundation.org/legal/generative-ai).
