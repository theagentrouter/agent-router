# Solution Logos

Logos for the "Solutions built on Agent Router" section of the homepage.

To add a solution, see [`site/src/data/solutions/README.md`](../../../src/data/solutions/README.md).
The easiest path is an external logo URL, which needs no file here. If you
prefer to host the logo in this repository:

- **Format**: SVG preferred (PNG also acceptable)
- **Shape**: Horizontal wordmark, shown at 28px height
- **Background**: Transparent
- **File naming**: lowercase with hyphens (e.g. `my-company.svg`)

Reference it from `solutions.json` as `"logoUrl": "/img/solutions/my-company.svg"`.
