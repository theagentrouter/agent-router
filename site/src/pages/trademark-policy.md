# Agent Router Trademark Policy

**July 2026**

The below guidelines supplement the LF Projects, LLC Trademark Policy, available at
[lfprojects.org/policies/trademark-policy/](https://lfprojects.org/policies/trademark-policy/).
Together, they govern use of the Agent Router trademarks. To the extent there is any
inconsistency between the Policies, this Agent Router Trademark Policy will control.

If you have questions with respect to this policy or to obtain written permission for a
proposed use of the Agent Router trademarks not addressed in this policy, please contact:
[trademarks@lfprojects.org](mailto:trademarks@lfprojects.org). Any amendments to this Agent
Router Trademark Policy must be approved by the Manager of LF Projects, LLC.

## Overall Guidelines

You may use the "Agent Router" Trademark to refer to the Agent Router software, provided
that your use is in compliance with this policy. Any other use of the Agent Router
Trademark requires prior written permission.

Overall, your use of the Agent Router Trademark must not be confusing, misleading, false,
or damaging to the Agent Router software, the Agent Router community or to the Agent
Router Trademark. People should always know who they are dealing with, and where the
software they are downloading and using came from. You may not use the Agent Router
Trademark in any manner that implies approval or endorsement by, or association with, the
Agent Router project or the Agent Router community, except to identify your organization
as a participant in the Agent Router Project. When using the Agent Router Trademark, your
branding should be distinguishable from Agent Router trade dress.

You may not use the Agent Router Trademark in a manner that may diminish or otherwise
damage the goodwill in the Agent Router Trademark. The "Agent Router" word mark should be
used in its exact form, and not abbreviated, converted to a different word form, or
otherwise modified. Similarly, the Agent Router logos should not be modified or
integrated with your logos or other designs.

Your use of the Agent Router Trademark does not transfer rights in the trademarks or
goodwill to you.

## Uses that do not require permission

Provided your use complies with this policy and our
[Brand Guidelines](https://github.com/theagentrouter/brand-assets), you may use the Agent
Router logos to link to the Agent Router website, to indicate that your software or
service uses the Agent Router software, in architecture diagrams to show how your
software or service integrates with Agent Router, and in presentations, social media
posts (but not as your account image or avatar), whitepapers, blog posts, and similar
content as a reference to the Agent Router project itself. It should be clear what role
the Agent Router project or software plays in the context of your software or services.
The Agent Router logos should not be more prominent than your own branding.

Use only the official versions of the Agent Router logos, available for download at
[github.com/theagentrouter/brand-assets](https://github.com/theagentrouter/brand-assets).
You may transform the file format itself for ease of use and modify the colors in
accordance with the [Brand Guidelines](https://github.com/theagentrouter/brand-assets).

Provided your use complies with this policy, you may use the "Agent Router" word mark to
accurately reference the Agent Router software, including on your website, in
presentations and publications, at events, in advertising and marketing material, etc.,
for commercial and noncommercial purposes.

You may use the "Agent Router" word mark and any logos the Agent Router project placed on
the software in connection with a redistribution of an official distribution of the Agent
Router software that has not been modified or changed in any way.

You may use the "Agent Router" word mark to make accurate statements about compatibility
and interoperability using relational phrases such as "works with," "runs on,"
"compatible with," and the like (e.g., "Foocorp Software powered by Agent Router" or
"Foocorp Software for Agent Router" or "Foocorp Software with Agent Router
compatibility").

## Uses that require permission

The following uses of the Agent Router Trademark require our prior written approval:

Those taking full advantage of the open source nature of the Agent Router code may make
modifications in accordance with the applicable open source license. You may use the
"Agent Router" word mark to identify or refer to your modified version of Agent Router if
you request and receive prior written approval and provided:

(a) you include an additional identifier indicating you as the source of the modified
version (e.g., "Foocorp's Agent Router Product" or "Foocorp Agent Router"),

(b) you clearly identify your modifications and indicate you are the source of the
modifications,

(c) your use does not suggest any affiliation between Agent Router or the Agent Router
community and you or your modified versions of Agent Router,

(d) your use of the "Agent Router" word mark should not be more prominent than your
additional identifier, and

(e) your use of the "Agent Router" word mark must not conflict with, or be confusingly
similar to, any previously approved use under this policy, as amended from time to time.

Those distributing, hosting, or otherwise taking advantage of the open source nature of
the Agent Router code may also offer services for, or software that works with, Agent
Router or modified versions of Agent Router. Users should not be confused as to the
source of your software or services. With that in mind, you may use the "Agent Router"
word mark to refer to services for, or software that works with, Agent Router or modified
versions of Agent Router if you request and receive prior written approval and provided
that:

(a) you include an additional identifier indicating you as the source of the software or
services (e.g., "Foocorp's Agent Router Tool" or "Foocorp Agent Router Service"),

(b) if your services or software works with modified versions of Agent Router, you
clearly identify the modifications and indicate the source of the modifications,

(c) your use does not suggest any affiliation between Agent Router or the Agent Router
community and you or your work,

(d) your use of the "Agent Router" mark should not be more prominent than your additional
identifier, and

(e) your use of the "Agent Router" word mark must not conflict with, or be confusingly
similar to, any previously approved use under this policy, as amended from time to time.

In addition, you must request and receive prior written permission for the following
uses:

- Use of the Agent Router logos in any way other than as expressly authorized by this
  Policy;
- Use as part of a domain name, except that you may use the Agent Router Trademark in a
  subdomain name provided your use otherwise complies with this Policy (e.g.,
  AgentRouter.foocorp.com); and
- Use with non-software goods or services (e.g., physical products like devices or
  services that do not directly use the Agent Router software), except that you may use
  the Agent Router Trademark with a limited number of swag or promotional items not for
  sale such as t-shirts, lanyards, stickers, mugs, or pens.
